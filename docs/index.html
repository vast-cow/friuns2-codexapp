Codex App UI

A browser interface for Codex app-server workflows, with conversations, local files, Skills and MCP servers.

The application runs a Node.js server on Windows or Linux. Desktop and mobile browsers can connect to that host.

Run from source

Install Node.js 18 or newer, pnpm, and a supported Codex CLI, then run these commands from the repository root:

pnpm install
pnpm run build
node dist-cli/index.js --no-open

Open the URL printed by the server and configure Codex authentication in the application.

The default port is 5900. Use --port to choose another port.
