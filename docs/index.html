Codex App UI

A browser interface for Codex app-server workflows, with conversations, local files, Skills, Plugins, and Apps.

The application runs a Node.js server. Android support uses Termux and a browser; this repository does not build a native Android APK.

Run from source

Install Node.js 18 or newer, pnpm, and a supported Codex CLI, then run these commands from the repository root:

pnpm install
pnpm run build
node dist-cli/index.js --no-open

Open the URL printed by the server and configure Codex authentication in the application.

Android with Termux

Install Node.js in Termux with pkg install nodejs, then use the same source build commands. Keep the Termux session running, disable battery optimization for Termux, and optionally use termux-wake-lock.
