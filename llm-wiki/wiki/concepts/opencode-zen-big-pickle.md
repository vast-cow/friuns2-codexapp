# Retired alternative-provider integration

OpenCode Zen, OpenRouter and custom endpoints are no longer supported by this client. The application uses official Codex app-server authentication, model catalogs, reasoning, approvals and streaming. Existing user configuration files and historical conversation metadata remain untouched. See [current implementation evidence](../../raw/features/codex-only-client.md).

Earlier raw sources linked from the wiki index remain immutable historical material and do not describe current provider support.
